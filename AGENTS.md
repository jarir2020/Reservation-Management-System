# AGENTS.md - Agent Context & Guidelines

## Overview
This repository contains a Restaurant & Reservation Management System written in PHP using CodeIgniter.

## Architecture Guidelines
- **MVC Architecture**: Models in `application/models/`, Controllers in `application/controllers/`, Views in `application/views/`.
- **Database Config**: Main database configuration file is at `application/config/database.php`.
- **Database SQL Dump**: Located in `database/elitede1_rest.sql`.

## Environment Setup
- Local MySQL Credentials: Host `127.0.0.1`, Port `3306`, User `root`, Password `root`.
- Default DB Name: `elitede1_rest`.
- Development Server command: `./start.sh` (or `php -S 127.0.0.1:8000`).
