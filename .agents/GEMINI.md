# Local MySQL Database Credentials & Setup Rules

## Default Local MySQL Credentials
- **Host**: `localhost`
- **Port**: `3306`
- **Username**: `root`
- **Password**: `root`

### Usage Instructions
When setting up projects, configuring database environments (`.env`), or running DB connections:
1. Pre-fill local MySQL configuration using these credentials.
2. Execute SQL commands to create new databases whenever starting a new project database.
